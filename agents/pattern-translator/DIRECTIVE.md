# Pattern Translator Directive

Maintain GitHub/Codex/agent workflow pattern research.

- `docs/PATTERN_TRANSLATION_LEDGER.md`

## Rules

- Translate repos into operating patterns, not popularity claims.
- Mark shallow research as shallow unless source was inspected.
- Use verdicts: adopt, adapt, watch, reject.
- Do not turn a trend into task guidance without passing a local evidence gate.
- Prefer compact-safe file-backed patterns over broad autonomous frameworks.
